Steps for success for first time users: 
1. Run this existing workflow in RunComfy: [Workflow](https://www.runcomfy.com/comfyui-workflows/my-workflows?shared_workflow=591f752a-4ced-25b5-0d06-3f6c66f9a48d)
2. Once it's loaded (takes a few mins to load), click the blue "Run" button
3. Only interested in using some of the workflow? Bypass the others by using CMD + drag to select what you don't want, and click on the triple dots option menu, and then select "Bypass."

Want to learn more? Visit the [repository.](https://github.com/CreativeInquiry/SFCI_ComfyUI_EasyVision)
